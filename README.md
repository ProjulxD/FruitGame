# FruitGame
## Objekte(erstmal bunte Kugeln) fliegen von unten nach oben
## Objekte können durch  schnedene handbewegungen zerstört(in zwei hälften) werden
## zwischendurch kommt auch eine Bombe diese darf nicht zerstört werden
## die objekte geben jeweils einen Punkt
## die Bombe gibt -3 Punkte
## die punkte werden gezählt und während der Runde oben links angezeigt
## die Steuerung erfolgt durch Handbewegungen die durch eine Kamera aufgenommen werden
## eine Runde geht 60 Sekunden
## nach einer runde soll man in einen Start screen kommen bei dem man die top 10 highscore werte ohne Namen sieht und durch das heben beider Hände in die luft soll eine neue Runde gestartet werden
## für die erkennung der Gesten soll ein bereits fertiges Modell verwendet werden
